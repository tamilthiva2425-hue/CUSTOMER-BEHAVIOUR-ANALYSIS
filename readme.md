# Customer Behaviour Analytics  ## Project Overview  This project analyzes customer behaviour, purchasing patterns, spending, and marketing campaign responses using Python, SQL, and Power BI.  The goal is to identify customer segments, understand spending behaviour, and generate business insights that can support marketing and customer-retention decisions.  ## Tools & Technologies  - Python - Pandas - MySQL - SQL - Power BI - DAX - Git & GitHub  ## Project Workflow  Raw Customer Data   ↓   Python Data Cleaning & EDA   ↓   Processed Customer Data   ↓   MySQL Database   ↓   SQL Analysis   ↓   Power BI Dashboard   ↓   Business Insights  ## Key Analysis Areas  - Customer spending behaviour - Customer demographics - Education-based spending - Age-based campaign response - Income-based spending - Marital-status spending - Marketing campaign response - Purchase behaviour  ## Power BI Dashboard  The dashboard provides an executive-level view of customer behaviour and purchasing patterns.  ### Key KPIs  | KPI | Value | |---|---:| | Total Customers | 2,237 | | Average Customer Spending | 605.74 | | Campaign Response Rate | 14.93% | | Average Purchases per Customer | 12.54 |  ### Dashboard Visuals  - Average Spending by Education - Response Rate by Age - Average Spending by Marital Status - Average Spending by Income Group - Education Filter  ## Project Structure  ```text CUSTOMER-BEHAVIOUR-ANALYSIS/ │ ├── data/ │   ├── raw/ │   │   └── marketing_campaign.csv │   └── processed/ │       └── customer_behaviour_cleaned.csv │ ├── database/ │   └── schema.sql │ ├── sql/ │   └── analysis_queries.sql │ ├── src/ │   ├── clean.py │   ├── database.py │   └── eda.py │ ├── powerbi/ │   └── Customer_Behaviour_Analytics.pbix │ └── README.md Business Insights  The analysis helps identify differences in customer spending and campaign engagement across demographic and income segments.  Higher-income customers show substantially higher average spending, while campaign response varies across age groups. Education and marital status also show differences in spending behaviour.  These findings can help businesses improve customer segmentation, target marketing campaigns more effectively, and prioritize high-value customer groups.
